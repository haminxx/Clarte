# Demo script (about 90 seconds)

## Before you start

- API Worker deployed with `XAI_API_KEY` and `GEMINI_API_KEY` set, library loaded into D1 and Vectorize.
- Website open full-screen, graph loaded (the node count shows bottom-right).
- Headphones on. Server VAD means the coach hears its own speaker otherwise.
- Have `nasa_t2:GSC-TOPS-40` ("CubeSat Form Factor Thermal Control Louvers") in the library — it is the
  node the drone-battery story lands on.

## The run

**0:00 — The constellation.** Full-screen graph, slowly rotating, roughly 700 dim nodes. One line:
"Every node here is a real paper, patent or NASA technology. Watch what happens when I describe a
problem."

**0:10 — Stage 1, Five Whys.** Tap the mic. Say: *"My drone battery dies way too fast."*
Clarte asks why, and keeps asking. Answer honestly for three or four turns — it gets to heat. The stage
pill stays on **5 Whys** and no documents are read out, which is the point: it is not answering yet.

**0:35 — The root cause.** Clarte says the root cause back: thermal management at high discharge rates.
Behind the scenes it has already called `search_tech`, so nodes start lighting up before it says
anything about them.

**0:45 — Stage 2, Why-How-What.** The pill moves to **Why · How · What**. Clarte collects why it matters
and how you would solve it, calls `find_related` with `cross_domain`, and the NASA CubeSat thermal
louvre patent and an NTRS thermal control report light up and pull the camera. It asks: *"How could you
apply this satellite technology to your pack?"* — say something concrete, like passive louvres over the
cell stack.

**1:05 — Stage 3, Debate.** The pill moves to **Debate**. Clarte calls `market_evidence`, Gemma 4 turns
the retrieved patents into objections, and it pushes: *"There is already a NASA patent on deployable
thermal louvres — what is your edge?"* Defend it once. It concedes that point and moves to the next
objection.

**1:25 — Idea card.** Tap "Make idea card". Problem, root cause, solution, three evidence documents
with links, and the biggest open risk. Close on: "Every claim in that card is a real document, and the
whole library is one MCP server, so Cursor can query it too."

## Lines worth saying out loud

- "21st.dev is a library of components for designers. This is a library of papers and patents for engineers."
- "It never gave me the answer. It made me find it, then it argued with me about it."
- "The objections are generated by Gemma 4 from real NASA patents — not from a model's memory."

## If voice is blocked

The risk flagged in plan section 10 is xAI credits. If the mic is disabled, the site says so and the
text box below it drives the identical tools:

1. Type the problem → `search_tech` runs, nodes light up, the retrieved documents list fills in.
2. Click a stage on the pill to move through the three stages yourself — the pill is clickable
   precisely so a presenter is not stuck waiting for the coach to advance it.
3. In the Debate stage the same box feeds `market_evidence`, so the cited objections still appear.
4. "Make idea card" still produces the closing artifact.

That path needs no xAI key at all — only the Gemini key for Gemma's objections, and even that has a
retrieval-only fallback.

## Recording checklist

- Under 2 minutes.
- Show the stage pill moving, at least one node lighting up, and one spoken citation.
- Show the idea card.
- Mention Cursor, Grok Voice and Gemma 4 by name once each.
